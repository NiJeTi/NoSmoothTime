# NoSmoothTime

This mod is for players who prefer a more dynamic in-game day-night cycle (**30x** or **60x**).
It makes global lighting update on a per-frame basis rather than on a per-second one, thus eliminating visible light and shadow nudges.

> [!NOTE]
> It only has a visual effect, so it can be used by any client without affecting anything on the server.
